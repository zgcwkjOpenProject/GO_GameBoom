# 炸弹人项目开发规范

本文件是本仓库开发、排查和代码审查的规范入口。开始工作前先阅读本文件；完成改动后按文末检查。项目实际行为以代码和测试为准

## 项目定位

炸弹人是一个 Go 服务端权威判定的多人网页对战游戏。浏览器通过 HTTP 加载原生 HTML、CSS 和 ES Module，通过 WebSocket 收发大厅、房间、输入和对局快照

## 目录职责

- `main.go`：服务启动、配置读取、监听和优雅关闭
- `api/`：HTTP 路由、静态资源和演示接口
- `game/`：服务端权威规则、房间大厅、WebSocket 生命周期、消息协议和对局循环
- `frontend/`：原生 HTML、CSS、JavaScript 前端，不依赖 Vue、Vite 或构建步骤
- `frontend/js/`：页面状态、WebSocket 协议、画布渲染、输入、音效与房主侧机器人决策
- `del/`：迁移前的 Vue/Vite/Node 实现，只作历史参考，不参与构建、测试或运行

## 构建

- 使用 PowerShell 7 执行根目录 build.ps1；脚本按构建时间生成静态资源版本
- 构建产物只放根目录 dist/；脚本压缩前端资源并为入口引用注入版本化缓存参数

## 通用约束

- 未经用户明确要求，不提交 Git、不创建提交、不代替用户打包
- 保留工作区已有改动，不擅自还原、删除或覆盖无关文件
- 优先沿用现有目录、模块和命名，不为未来需求增加抽象或依赖
- 函数和方法即使只有一条语句，也使用常规多行函数体
- 代码、文档、脚本输出和提交说明只记录实际行为、必要约束和维护信息
- 改动覆盖到的自有文件，顺手补齐其中原本缺失的注释
- 构建产物只放在根目录 `dist/`，临时构建与本地测试文件只放在根目录 `build/`
- 本地测试启动服务时使用独立端口；结束前停止进程并确认端口已释放

## 注释规范

- 每个 Go、JavaScript、PowerShell 和 Shell 函数或方法都要有上一行简短中文用途注释
- Go 文件的 `package` 声明前必须有简短中文包注释
- Go 函数注释按 GoDoc 习惯以函数名开头；JavaScript 使用自然中文说明用途或原因
- JavaScript 注释直接描述用途或原因，不以函数名或变量名开头，例如使用“返回指定格上的炸弹”，不要使用“bombAt 返回指定格上的炸弹”
- 变量、常量和重要结构字段需要中文注释，尤其是配置、协议字段和并发状态
- `const (...)` 块内紧邻常量声明的说明写在声明行尾；独立 `const` 使用上一行说明
- 注释必须与当前实现一致，不为显而易见的语法补充无意义注释
- 注释末尾不加中文或英文标点；CSS 注释保留 `/* */`，JavaScript 单行注释使用 `//`

## 服务端与协议

- `game/` 仅处理游戏规则，不读写 WebSocket，不信任浏览器状态
- `game/Hub` 的单个循环拥有房间和对局状态；WebSocket 收发 goroutine 只能通过 channel 交给 Hub
- 浏览器只发送昵称、房间操作和输入；机器人输入只允许房主发送。位置、碰撞、炸弹、伤害、道具和结算必须由服务端计算
- 新增或修改 WebSocket 消息时，同时更新 `game/wire.go`、对应前端解析和 `game/` 测试
- 不让慢客户端阻塞房间循环；发送队列满时按当前 `Client` 生命周期策略断开连接
- 用户昵称和房间名称必须在服务端清洗，前端显示外部文本必须使用 `textContent` 或等价安全 API
- 断线玩家退出房间；对局内断线按当前规则结算，不能留下不可恢复的房间或对局状态

## 前端和缓存

- 前端使用原生 ES Module，不引入 Vue、Vite、Node 运行时或其他构建依赖，除非用户明确要求
- 复用 `frontend/js/common.js` 的 DOM 工具；外部输入不能拼接到 `innerHTML`
- 布局优先使用 Flex，只有 Flex 无法表达时使用 CSS Grid
- 画布只负责渲染服务端快照和短时视觉插值，不得成为游戏规则来源
- 静态 HTML 和无扩展名入口使用 `Cache-Control: no-store`；未版本化静态资源最多缓存一天
- 修改浏览器交互时，使用 CDP 验证页面、关键 DOM 状态、画布尺寸和控制台错误

## 音频编曲

- `frontend/js/game-audio.js` 中的 `LOBBY_TRACK` 使用音符频率数组，数字单位为 Hz，不是生命值或其他游戏数据
- 常用中央音阶频率：哆 `261.63`、唻 `293.66`、咪 `329.63`、发 `349.23`、嗦 `392`、啦 `440`、西 `493.88`；高八度频率约为其两倍
- 大厅旋律使用原创八位机风格编曲，方波音色，普通音符约 `0.16` 秒、间隔约 `0.19` 秒，最后一个收尾哆音约 `0.52` 秒
- 大厅音乐可以借鉴经典主机的音色、节奏和氛围，但不直接复制《Bomberman NES》等既有作品的原曲旋律

## 历史代码

- `del/` 中的 Vue/Vite/Node 文件是迁移前实现，不参与当前功能修改
- 只有用户明确要求追溯或删除历史实现时才修改 `del/`
- 从历史代码迁移行为时，先在 Go 与原生前端实现并添加对应测试，不恢复旧运行链路

## 测试和交付检查

完成改动后按影响范围执行：

```powershell
go test ./...
go vet ./...

Get-ChildItem frontend/js -Filter *.js | ForEach-Object { node --check $_.FullName }
git diff --check
```

涉及浏览器交互时，使用 `go run . -addr :5174` 或独立端口启动服务，并通过 CDP 验证登录、大厅、房间、开局和控制台错误；测试结束后停止服务并释放端口。新增 Go 测试应与被测包放在 `api/`、`game/` 或根目录中，优先覆盖公开行为和协议回归
